# Markdown 语法指南

> Markdown 是一种轻量级标记语言，让你能够使用易读易写的纯文本格式编写文档，然后转换成有效的 XHTML（或者 HTML）。

>Markdown 是一种轻量级标记语言，让你可以用纯文本格式写出结构清晰的文档。**学会它只需要 10 分钟，但之后每一篇文章都会受益。**


## 一、标题

Markdown 支持 6 级标题，`#` 的个数代表标题级别。

```markdown
# 一级标题（通常每篇文章只用一次）
## 二级标题（章节标题）
### 三级标题（小节标题）
#### 四级标题
##### 五级标题
###### 六级标题
```
演示：

<span style="font-size: 24px;">二级标题</span>
<span style="font-size: 20px;">三级标题</span>
<span style="font-size: 18px;">四级标题</span>
<span style="font-size: 16px;">五级标题</span>
<span style="font-size: 14px;">六级标题</span>

## 二、段落与换行
段落是由一个或多个段落文本组成，多个段落之间用一个或多个空行隔开。
段落中的换行符会被转换为换行，段落中的空白会被转换为空格。
```markdown
这是一段段落。 
    （中间需要有空行）
这是另一段段落，
```
演示：

这是一段段落。

这是另一段

## 三、强调与样式

### 基础强调

| 效果 | 语法 | 示例 | 渲染效果 |
|------|------|------|----------|
| **粗体** | `**文字**` 或 `__文字__` | `**重要内容**` | **重要内容** |
| *斜体* | `*文字*` 或 `_文字_` | `*侧重点*` | *侧重点* |
| ***粗斜体*** | `***文字***` | `***强调中的强调***` | ***强调中的强调*** |
| ~~删除线~~ | `~~文字~~` | `~~不推荐的内容~~` | ~~不推荐的内容~~ |

> 💡 **提示：** **粗体** 和 *斜体* 组合使用时，注意符号顺序

### 实用建议

✅ **推荐使用：**
- 用 **粗体** 强调关键信息
- 用 *斜体* 表示术语或外来词
- 用 `行内代码` 标注技术名词、命令、文件名
- 用 ~~删除线~~ 表示过时或不推荐的内容

❌ **避免使用：**
- 不要过度使用强调，保持适度
- 不要在标题中使用过多强调
- 避免在同一位置使用多种强调方式


## 四、列表

### 无序列表
使用 `-`、`+` 或 `*` 加空格创建无序列表（三种符号效果相同）：

```markdown
markdown
-项目一
-项目二
-项目三
或者使用：
+项目一
+项目二
也可以使用：
*项目一
*项目二
```

**效果：**

- 项目一
- 项目二
- 项目三

---

### 有序列表

使用数字加点和空格创建有序列表：

```markdown
1. 第一项
2. 第二项
3. 第三项
4. 第四项
```

**效果：**

1. 第一项
2. 第二项
3. 第三项
4. 第四项

> 💡 **提示：** Markdown 会自动排序，即使全部写成 `1.` 也会自动递增显示为 1、2、3...

---

### 嵌套列表

可以在列表中嵌套其他列表，子列表需要缩进 2 个或 4 个空格：

```markdown
1. 第一项
   - 子项一
   - 子项二
     - 更深层的子项
2. 第二项
   1. 有序子项一
   2. 有序子项二
```

**效果：**

1. 第一项
   - 子项一
   - 子项二
     - 更深层的子项
2. 第二项
   1. 有序子项一
   2. 有序子项二

---

```markdown
- 项目一
- 项目二
```

如果需要在文本中显示列表符号而不创建列表，使用反斜杠转义：

```markdown

\- 这不是列表

2\. 这也不是列表

- 这是列表
- 这是列表
```

### 最佳实践

✅ **推荐做法：**
- 保持一致的列表符号风格
- 嵌套列表时统一使用 2 或 4 个空格缩进
- 列表项较长时，在列表前后添加空行
- 任务列表用于追踪进度非常实用

❌ **避免做法：**
- 不要混用不同的列表符号（如同时使用 `-` 和 `*`）
- 避免过深的嵌套层级（建议不超过 3 层）
- 不要在列表项之间随意添加或删除空行

### ⚠️ 注意：HTML 块级标签内的 Markdown 可能不解析

在 `<div>`、`</td>` 等块级 HTML 标签内部，标准 Markdown 语法（如 `**粗体**`、`*斜体*`、`[链接]()`）可能不会被解析。

**解决方案：**

| 方案 | 写法示例 | 说明 |
|------|----------|------|
| 用 `<br>` 换行 | `第一行<br>第二行` | 最简单的换行方式 |
| 显式写 HTML 标签 | `\<strong\>粗体\</strong\>` 代替 `**粗体**` | 用 HTML 标签替代 Markdown 语法 |
| 改用行内 HTML 标签 | `<span>**这样写依然不解析**</span>` | 尽量避免在块级标签内写 Markdown |

**正确示例：**

```html
<div>
  <strong>这样写可以加粗</strong><br>
  这是第二行
</div>

```

## 十一、写在最后

### 本文档的作用

这份指南涵盖了 Markdown 的**常用语法**和**进阶技巧**，包括：

- 标题、段落、列表等基础语法
- 表格、代码块、引用等常用功能
- 转义字符、HTML 混用等进阶内容
- VuePress 特有的语法高亮扩展

### 使用建议

1. **按需查阅**：不需要一次性背完所有语法，用到哪块翻到哪块
2. **边写边练**：打开编辑器，每学一个语法就动手试一下
3. **保持简单**：80% 的场景只需要标题、列表、链接、代码块这四种语法

### 下一步学什么？

如果你已经掌握了 Markdown 基础，可以继续学习：

| 方向 | 内容 | 推荐程度 |
|------|------|----------|
| VuePress 扩展 | 提示框（`::: tip`）、代码块行号、自定义容器 | ⭐⭐⭐⭐⭐ |
| 数学公式 | LaTeX 语法，适合技术博客 | ⭐⭐⭐⭐ |
| Mermaid 图表 | 流程图、时序图、甘特图 | ⭐⭐⭐⭐ |
| Frontmatter 配置 | 分类、标签、永久链接等元数据 | ⭐⭐⭐⭐⭐ |
