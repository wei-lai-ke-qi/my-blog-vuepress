# 从零开始搭建博客

> 记录从 0 到 1 搭建个人博客的过程，顺便开启一个「博客搭建系列」

## 前言

搭建博客，除了要考虑技术本身，还要考虑很多其他方面。

### 叠甲声明（又名：菜鸡互啄警告）

在开始之前，有几句话想先说清楚：

> 🛡️ **甲一**：我不是前端大佬，也不是运维专家，只是一个会点代码、喜欢折腾的普通人。这篇教程是我边踩坑边记录的产物，不是"标准答案"，更不是"最佳实践"。

> 🛡️ **甲二**：教程里的命令、配置、思路，都是我实际跑通过的。但你的电脑环境、Node 版本、网络状况可能和我不一样，遇到报错非常正常——**建议把报错信息复制到 AI 里问一下**，大概率能解决。

> 🛡️ **甲三**：如果你在某步卡住了，不一定是你的问题，也不一定是教程的问题。有时候关掉终端重开、删掉 node_modules 重装、甚至重启电脑，都比纠结原因更高效。

> 🛡️ **甲四**：我会尽量讲清楚"为什么这么做"，而不仅仅是"复制这段代码"。因为只有理解了原理，你才能改出自己的博客，而不是我的复制品。

> 🛡️ **甲五（终极甲）**：如果你全程跑通并且觉得有用，那是你的执行力和学习能力强，和我关系不大；如果你跑不通，可以评论区留言，我们一起想办法——**毕竟我也是现学现卖，刚好走在你前面一点点。**

**总结：我其实也不咋会，只是比你早踩了几个坑而已。一起加油！**

### 为什么突然想搭博客？

理由其实很简单——想有一个真正属于自己的写作空间。

- 写笔记太零散，不好回顾
- 发平台要考虑审核和推荐算法
  - 想换个主题、加个评论都要看平台的脸色

最后折腾了一周，选择了 **VuePress** 这套方案。

### 技术选型：为什么是 VuePress？

| 方案 | 优点 | 缺点 |
|------|------|------|
| Hexo | 生态丰富，主题多 | Node 环境，主题定制略麻烦 |
| Hugo | 极快，二进制单文件 | 模板语法学习成本稍高 |
| **VuePress** | 熟悉 Vue，原生支持多级目录，文档友好 | 中文站速度稍慢 |

我是前端背景，用 Vue 写主题、改样式都很顺手，所以选了 VuePress。

## 搭建过程

- [VuePress 官方文档](https://vuepress.vuejs.org/zh/guide/getting-started.html)
### 0. 前期准备

在开始之前，建议先准备好以下内容：

1. **基础知识**：了解基本的终端命令，会使用 AI 工具解决报错问题
2. **代码编辑器**：任意前端开发工具均可，推荐：
   - [VSCode](https://code.visualstudio.com/)
   - [WebStorm](https://www.jetbrains.com/webstorm/)
   - [HBuilder](https://www.dcloud.io/hbuilderx.html)
3. **GitHub 或 Cloudflare 账号**：用于免费部署博客
4. **一个域名**（可选但推荐）：让博客更有辨识度

### 1. 安装 Node.js

打开 [Node.js 官网](https://nodejs.org/)，下载 **LTS 版本**（长期支持版，更稳定）。

双击安装包，一路点击"下一步"即可，不需要修改任何设置。

**验证是否安装成功：**

打开终端（Windows 用 CMD 或 PowerShell，Mac 用终端），输入以下命令：

```
# 查询 Node 版本
node -v
# 查询 npm 版本
npm -v
```
输出结果类似：
```
C:\Users\用户名>node -v
v18.17.0

C:\Users\用户名>npm -v
9.6.7
```
如果看到版本号，说明安装成功。

💡 如果提示“不是内部或外部命令”，说明安装时没有自动加入环境变量，可以重装 Node.js，注意勾选“Add to PATH”

### **2、创建项目文件夹**
在电脑上找一个合适的位置，新建一个文件夹作为博客项目的根目录：

```bash
mkdir my-blog
cd my-blog
```
或者直接在桌面手动创建文件夹，然后用终端进入该目录。


### **3、初始化项目**
在项目目录下打开终端，运行以下命令：
```bash
npm init -y
```
-y 表示所有选项都使用默认值，会自动生成 package.json 文件。如果你想手动填写信息，也可以不加 -y。

### **4、安装 VuePress**
在项目目录下执行：

```bash
npm install -D vuepress@next
```
@next 表示安装 VuePress v2 版本（基于 Vue 3）。如果需要 v1 版本，可以换成
```bash
npm install -D vuepress
```
等待安装完成，你会看到：
* node_modules 文件夹（依赖包）
* package-lock.json（版本锁定文件）

### **5、添加 npm 脚本**
打开 package.json 文件，在 "scripts" 中添加两行：

```json
{
"name": "my-blog",
"version": "1.0.0",
"scripts": {
   "dev": "vuepress dev docs",      
  "docs:build": "vuepress build docs"   
},
"devDependencies": {
"vuepress": "^2.0.0"
}
```
* dev：启动开发服务器，实时预览
* docs:build：打包生成静态文件


### **6、创建 docs 目录和第一篇文档**
VuePress 默认将文档放在 docs 目录下：

```bash
mkdir docs
```
在 docs 目录下创建 README.md 文件：
```bash
echo "# Hello My Blog" > docs/README.md
```
你也可以手动创建这个文件，写入：

```
# 欢迎来到我的博客

这是我的第一篇博客内容，VuePress，启动！
```
README.md 会被自动识别为博客首页。

### **7、首次运行**
在项目根目录下执行：

```bash
npm run docs:dev
```
如果一切顺利，你会看到类似这样的输出：

```
✔ Initializing and preparing data - done
✔ Compiling with vite - done
✔ Starting dev server - done
vuepress dev server running at http://localhost:8080/
```
打开浏览器访问 http://localhost:8080/，就能看到你的博客页面了！

### **8、配置 VuePress**
在 docs 目录下创建 .vuepress 文件夹，并在里面新建 config.js 配置文件：

```bash
mkdir docs/.vuepress
touch docs/.vuepress/config.js   # Windows 可用 New-Item 命令
```
编辑 config.js：

```javascript
import { defineUserConfig } from 'vuepress'
import { defaultTheme } from '@vuepress/theme-default'

export default defineUserConfig({
lang: 'zh-CN',
title: '我的博客',
description: '记录学习和生活',
    theme: defaultTheme({
        navbar: [
            { text: '首页', link: '/' },
        ],
    }),
})
```

### **9、写一篇文章**
在 docs 目录下创建文章文件，例如：

```bash
mkdir docs/第一篇博客
echo "# 我的第一篇博客" > docs/第一篇博客/README.md
```
VuePress 支持多级目录结构，每个文件夹下的 README.md 或 .md 文件都会自动生成对应的路由。

### **10、部署到 GitHub Pages**
#### 安装 gh-pages 插件
```bash
npm install -D gh-pages
```

#### 添加部署脚本

在 package.json 的 "scripts" 中添加：

````json
"deploy": "npm run docs:build && gh-pages -d docs/.vuepress/dist"
````
#### 创建 GitHub 仓库
登录 GitHub，点击右上角 + → New repository

Repository name 填写 用户名.github.io（例如 zhangsan.github.io）

选择 Public，点击 Create repository

#### 推送代码并部署 
```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/用户名/用户名.github.io.git
git push -u origin main
npm run deploy
```
部署完成后，访问 https://用户名.github.io 即可看到你的博客。

## 常用命令总结

| 命令 | 说明 |
|------|------|
| `npm run docs:dev` | 启动本地开发服务器 |
| `npm run docs:build` | 打包生成静态文件 |
| `npm run deploy` | 打包并部署到 GitHub Pages |

## 结语
到这里，你已经从零开始搭建了一个属于自己的博客！

整个过程虽然遇到一些小坑，但当你看到浏览器里出现自己亲手搭建的页面时，那种成就感是值得的。
